# Git с нуля — Peaky Minds

Учебные снимки терминала для бесплатного курса https://stepik.org/course/302363

35 изображений показывают фактический вывод Git Bash 2.51.1 на Windows в изолированном учебном репозитории. Команды, полный вывод и коды завершения сохранены в transcripts.json. Изображения — снимки браузерного просмотра записи терминала; вывод не был придуман или сгенерирован изображением.

Хеши коммитов, даты, пути и оформление на компьютере учащегося могут отличаться.
